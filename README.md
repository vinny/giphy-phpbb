This extension integrates Giphy into the standard phpBB posting editor and private messages, allowing your users to search and insert GIFs into their posts with just a few clicks.

**Main Features:**
* **Editor Integration:** Adds a dedicated "GIF" button directly to the phpBB posting editor (works for both topics/replies and private messages).
* **Live Search:** Built-in modal window with a fast, responsive search bar to find the perfect GIF in real-time.
* **Trending GIFs:** Automatically displays currently trending GIFs when the search bar is empty, providing instant inspiration (curated by Giphy).
* **BBCode Insertion:** Automatically inserts the selected GIF directly into the textarea using standard `[img]` BBCode tags.
* **Responsive Modal UI:** The search modal is fully styled and responsive, ensuring a great experience on both desktop and mobile devices.

**Requirements:**
* A free Giphy API Key (obtainable at [developers.giphy.com](https://developers.giphy.com/))
